# CARAT research artifact

This directory is the executable artifact accompanying the TPDS-oriented journal manuscript.
It contains the implementation, independent checkers, deterministic tests, lawful public inputs, experiment drivers, and retained results.

Run the complete local reproduction:

```bash
./scripts/reproduce.sh
```

The evaluated model is fixed-roster, faithful-origin, crash-stop operation with bounded local resources. It does not claim Byzantine security, dynamic membership, WAN performance, or production deployment.
